# 0038: context-live's back-history to 2017, in two editions, for skill-over-expected's H84

**Date:** 2026-11-20 · **Decided by:** the CEO chose the method (2026-11-20: "Let's run the context model back to 2016 and then rerun the third look using over expected metrics. Eventually we will want to add yards after contact and broken tackles to the context expert, we can do that now or later."). The calls below are Claude's technical calls, listed for veto at merge. · **Project:** `skill-over-expected` (it uses `context-live`'s method; the shipped champion is unchanged)

**Decision:** `pcf.experts.context_live.back` gives context-live's expectations for pressure, sack, completion, time to throw, depth of target and rushing yards on every play from 2017 to 2024, walk-forward, in two editions. It is saved as `outputs/context-live/<run_id>/back_<edition>.parquet` in the standard schema, with `model_version` `back-situation` or `back-calls16`.

**The calls:**

1. **Fields every season has, not the shipped ones.** The shipped model reads FTN's calls (play action, screens, blitzers, motion), which start in 2022. Running it on 2016-2021 would leave those fields empty, and the same player would be measured against a different model before and after 2022. That is the kind of break that made the third look's sacks per pressure repeat 0.61 for everyone. So each edition uses one field set for every season.
2. **Two editions.**
   - **situation:** the situation alone, the CEO's words ("relative to situation"). The situation removes little of these outcomes. In the 2023-2024 backtest: pressure 0.7% of squared error, sack 0.6%, completion 1.5%, rushing yards 0.7%, time to throw 1.3%, depth 4.3%. A measure over it will be close to the plain rate.
   - **calls16:** the situation plus the calls charted since 2016: the play-by-play's shotgun and no-huddle, and participation's pass rushers and defenders in the box. This is the nearest to the context expert as built ("the situation and both sides' calls") across all seasons. Participation's formation and personnel are left out because their coding changed in 2023 (for example, "UNDER CENTER" and full-roster personnel strings appear).
3. **calls16 is retrospective** (rule m). Participation is published after the season, so these rows' `as_of` is the later of the game's and participation's known-at, and their `cadence` is `retrospective`. It never feeds an in-season model. This is an exploration's edition, not the planned `context-retro` expert, which still needs the CEO's sign-off as a new expert.
4. **The methods are the 2023-2024 backtest's.** The situation edition uses each outcome's chosen situation rung. The calls edition uses the shipped live rung's method (linear for pressure and sack, trees for the rest). There is no new ladder, because this is an input to a discovery look, not a new champion.
5. **Training starts in 2016** (participation's first season), once per test season, recency-weighted (half-life 4), and is checked to be known before the test season's first `as_of` (`run.training_rows`). The test seasons are 2017-2024, and the 2025 vault is never read.
6. **The provider rule for pressure and time to throw** (`context-live#R12`): test seasons through 2023 train from 2016, so 2023 trains on the old provider only, and 2024 trains on 2023 alone. Because the level differs across the change, a user takes each season's league level out before comparing seasons. The share each expectation removes is reported that way (`back_<edition>.json`).
7. **Yards after contact and broken tackles wait.** No free source has contact at play level: PFR's numbers are per player-game. An expectation for them would have to be per game, from the situations of that game's carries. It is a small design of its own, logged as idea I92, for when we add them to the context expert.
